# Generated design concepts

Preview concepts generated with the built-in image-generation tool. These are not screenshots of the implemented application. Images are for direction selection; type, spacing, content and interaction behavior must be reconciled with the proposal before implementation.

- [B — Graphite Lab](b-graphite-lab.png)

The full plan is [Interior redesign proposal](../INTERIOR_REDESIGN_PROPOSAL.md).

## Art-direction review

A is the recommended base. The conceptual diagrams make subjects distinctive while solid surfaces preserve reading comfort. In production, render these diagrams from code or the existing visualizers, with separate readable labels, rather than embedding a screenshot.

B is an alternate dark identity. Reduce the strength of its amber frame in long sessions and retain strong text contrast. C is a bolder alternate; use only the right-side learning sequence, removing the repeated mini sequence inside its continue panel. These generated details are not binding specifications.

All three show a representative subset of subjects, not the full catalog. Existing Networks and AI routes remain part of implementation. The title and lesson labels are illustrative, and the existing logo geometry remains the source of truth.

## Prompt set

### 1. cobalt

Use case: ui-mockup. Generate a high-fidelity, exceptionally art-directed desktop web application design concept for ApexCaliber, an engineering study platform for students and graduates learning foundations, DSA, Python, SQL, operating systems, backend APIs, networks, AI and system design. This is the authenticated learning home AFTER login, not the public marketing homepage. Flat front-on screen, no laptop, no perspective, no desk, no background outside the application. Wide 16:10 aspect ratio, sharp crisp legible typography, complete composition. Mature designer-crafted product with meaningful conceptual mini-illustrations, immaculate alignment, deliberate whitespace, strong hierarchy. Plenty of visual craft and detail but readable. No cream, no green dominant palette, no purple, no neon galaxy, no mountains, no gamification XP, no fake revenue charts, no decorative trophies. Do not use photos or avatars of people. Preserve practical learning UI. Navigation labels include Learning home, Subjects, Practice, Progress, Interview prep. Small geometric ApexCaliber summit logo at top left, wordmark. Search command input in top bar; theme control and initials avatar at right, logout hidden. Main title 'Build understanding. Then write code.' Subline 'Your next lesson, ready when you are.' A prominent continue-learning module with 'DSA FOUNDATIONS', title 'Arrays & two pointers', supporting text 'See how a pair of pointers turns a search into a strategy.', single clear 'Continue lesson' action, simple three-step label 'Understand / Explore / Check'. Mini visual showing real numbered array tiles 2, 7, 11, 15 with pointers, as the product signature. Below: 'Explore subjects', visually engaging subject cards for 'DSA', 'Python & data', 'SQL & databases', 'Operating systems', 'Backend & APIs', 'System design'. Each has small subject-specific technical diagrams (array blocks, code brackets, relational table, thread lanes, API nodes, architecture flow), a readable title and short learning description. Those visual covers are designed to animate on hover eventually. Use realistic, concise English labels. No invented performance metrics. Create an original design inspired by the precision of Linear and the component quality of shadcn, not copied branding.
DIRECTION A: 'Cobalt Studio'. Light, modern, premium and inviting. Cool platinum canvas #F3F5F9, brilliant white solid reading surfaces, ink navy #162033, cobalt #315EFB for primary actions, slate #6C788C for metadata, subtle ice-blue tints. Strong but compact geometric sans headlines resembling Sora, refined Inter body, JetBrains Mono code labels. A slim 204px white left navigation rail with section labels and thin blue active indicator; main content aligned on an 8px grid, 28px gutters. Heading at upper left, quiet outline 'View syllabus' action aligned at right. Main continue module is an asymmetric wide 2-column feature: generous typography on left, elegant white-to-ice-blue 3D-ish algorithm stage on right. Render array tiles as translucent blue edged acrylic on a faint precision grid with subtle shadows; all text stays on opaque surfaces. A tiny frosted-glass playback capsule over the illustration, with play and step icons, is the ONLY glass focal point. Below, 3-column subject card grid, very refined 12px corners, slim gray borders, each with a 80px height original technical illustration in mostly blue/gray with small distinct muted category cues. Primary CTA rectangular with 8px radius; no giant pill controls. Beautiful depth from subtle shadows and layers rather than luminous glows. It should feel like a polished specialist learning product with visual character, not a generic admin panel. Make the interface attractive enough to invite exploration, with no excessive empty space.
